This page runs the generator itself — this repository's own source, built to JavaScript — in the tab you are reading it in. Edit the spec on the left; the routes, the service code, the OpenAPI document and the findings follow as you type. Nothing is uploaded, and nothing is pre-computed: every character on the right came out of the library just now.

    What the panes hold
    
      
    
        Service is what gen api would write for this spec: the
        build_app function with its routes wired to handlers, the types, and the
        constraint checks the tags imply. OpenAPI is the document
        gen doc produces, as JSON. Findings is what
        mctl api validate reports — a handler named twice, a route with no
        @handler, a tag the generator cannot honour.
      
    
      
    
        A spec the parser cannot read stops it, and the error names the line. That is the same
        refusal the command line gives: nothing is generated from a spec that was only half read.
